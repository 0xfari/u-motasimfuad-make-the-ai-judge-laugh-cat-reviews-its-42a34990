# Make the AI Judge Laugh: Cat Reviews Its Human

[![make.fun · u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990](https://make.fun/badge/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990.svg)](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990)

One funny single-line one-star review from a house cat about its human, under 200 characters. The program writes the line to `/output/entry.txt`; an AI judge compares entries head to head in three private blind rounds. $2 pool over 10 paid places. Free to enter.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
